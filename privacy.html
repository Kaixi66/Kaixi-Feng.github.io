Privacy & analytics

Updated October 15, 2026. This personal homepage uses analytics to understand its readership and improve the reading experience. The statistics dashboards are private.

Basic traffic statistics

Cloudflare Web Analytics measures page views, visits, countries, referring sites, devices and page performance. It does not use cookies or local storage to recognize visitors. Its visit counts do not represent unique people. About Cloudflare Web Analytics.

Optional visitor analytics

Statcounter and Microsoft Clarity load only for browsers with an existing saved approval from the earlier analytics settings. The homepage no longer presents an analytics prompt or settings button. New visitors without that approval receive only the basic Cloudflare statistics. The optional services may receive your IP address and information about your browser, device, page URL, referrer and visit time.

Statcounter uses a cookie to estimate first-time and return visits and reports approximate cities or regions based on IP addresses. These locations can be inaccurate, particularly when a VPN, proxy or shared network is used. Its free plan retains detailed records for the most recent 500 page views. Statcounter privacy policy.

Microsoft Clarity uses cookies and records interactions within this page, including clicks, scrolling and navigation, to generate heatmaps and session replays. This helps me understand which publications interest readers and where the page is difficult to use. Clarity masks sensitive content by default. The site sends named events for paper, Google Scholar and email-link clicks; it does not send a custom name, email address or other identity for a visitor. Advertising storage consent is denied. Microsoft processes usage data under the Microsoft Privacy Statement.

Your choices

You can turn off optional analytics. This stops new collection by Statcounter and Clarity; basic Cloudflare statistics continue.

You can also exclude this browser from all three analytics tools. This saves a local preference in this browser. You can restore statistics; optional tools still require a previously saved approval. Clearing site data, changing devices or using a different browser resets the preference. If your browser prevents saving preferences, optional tools remain off.

Your choices apply to future collection. Previously collected records are not automatically removed by changing a browser preference. Ad blockers and network conditions can prevent visits from being counted.

Hosting and other requests

GitHub Pages hosts this site. Page requests are subject to the GitHub Privacy Statement. Google Fonts supplies the typeface and receives the network requests needed to deliver it.
